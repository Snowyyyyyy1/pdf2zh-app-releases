# pdf2zh-app releases

This public repository hosts the installers and update metadata for pdf2zh-app. The development repository is private; each published release will include the corresponding AGPL-3.0 source archive alongside the installers.

Windows installations check this repository for `latest.yml`, download new NSIS installers in the background, and install an update when the user chooses to restart. macOS automatic installation will be enabled only after a signed release build is available.

No release has been published yet.
